# DecisionVault 0.5.0-alpha.1 — Executive Dashboard Framework

Sprint 5.1.1a introduces the reusable executive dashboard framework while
preserving the existing `/api/v1/dashboard` API and database.

## Included

- Executive Decision Intelligence landing page.
- Responsive six-metric executive scorecard.
- Data-driven executive briefing.
- Reusable dashboard widget container.
- Reusable executive metric component.
- Decision and knowledge health visualization.
- Governance posture visualization.
- Recent audit activity feed.
- Executive quick-action panel.
- Loading, refresh, empty, and error states.
- No additional frontend chart dependency.
- No database or backend changes.

## Next Increment

Sprint 5.1.1b will expand the backend dashboard contract with:

- Open, high-risk, overdue, and approval-stage decision metrics.
- Readiness distribution.
- Risk and status chart series.
- Business-unit aggregation.
- Richer executive insights.
