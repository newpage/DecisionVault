# Roadmap working agreement

The [Platform Capability Map](PLATFORM-CAPABILITY-MAP.md) separates current capability from transitional, target, and conditional future evolution. It is architectural direction, not a release commitment.

Use `docs/ROADMAP.md` for outcome-level engineering direction. Add dated or milestone-specific plans in this directory only after ownership and acceptance criteria are known. Roadmap items are not shipped behavior, API contracts, or architectural decisions; record those in release notes, API docs, or ADRs respectively.
